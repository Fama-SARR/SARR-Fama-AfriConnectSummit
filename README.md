# AfriConnect Summit 2026

**Nom :** Fama Sarr
**Classe :** L1IAGE 

## Description du projet
Site vitrine complet pour une conférence tech panafricaine fictive, "AfriConnect Summit 2026". Le site présente l'événement, son programme sur 3 jours, ses intervenants, et permet l'inscription des participants via un formulaire de contact.

## Technologies utilisées

- HTML5 sémantique
- CSS3 (Flexbox, Grid, variables CSS, animations, responsive design)
- JavaScript vanilla (aucun framework)
- Google Fonts (Sora, Inter)
- Bootstrap Icons

## Fonctionnalités JavaScript implémentées

- Dark mode / Light mode avec sauvegarde localStorage
- Navbar dynamique au scroll
- Menu hamburger responsive
- Année dynamique dans le footer
- Bouton retour en haut
- Onglets du programme (Jour 1/2/3)
- Filtrage des intervenants par thématique
- Validation complète du formulaire de contact (regex email, téléphone, longueur du message)
- FAQ en accordéon CSS pur
